# LankaPriceAI

LankaPriceAI is a machine learning-based web application for analysing historical rice prices and exploring future rice price forecasts in Sri Lanka.

### Main Features
- Historical rice price analysis
- Exploratory Data Analysis (EDA)
- Machine learning model comparison
- Rice price forecasting
- Market price comparison

### Technologies Used
- Python
- Pandas, NumPy and Scikit-learn
- Random Forest, XGBoost, LightGBM and CatBoost
- Streamlit
- Jupyter Notebook
